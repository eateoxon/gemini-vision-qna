# Gemini Vision Q&A
A stateless web application that allows users to upload an image, ask a natural-language question about it, and receive a precise answer using the Gemini API.
Deployed as a public service on Google Cloud Run. 
No authentication, no DB.

## Stack
- Backend: FastAPI (Python)
- Frontend: Plain HTML + vanilla JavaScript
- AI: Gemini Flash models
- Deployment: Google Cloud Run

MVP in progress.
